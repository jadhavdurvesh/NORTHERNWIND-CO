# Northernwind & Co

Immersive website for **Northernwind & Co**, a DMJ Group company. The experience is positioned around the service agreement: social-media/content support, recurring monthly deliverables, platform coverage, and Basic / Growth / Premium / Custom packages.

## Stack
React + Vite + Framer Motion + Lucide React.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Visual direction
Dark northern atmosphere, icy editorial typography, animated wind-flow lines, mountain silhouettes, and restrained motion.
